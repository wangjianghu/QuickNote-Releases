# QuickNote

macOS 本地 Markdown 随手笔记。用一个小窗口快速记下内容，不必切换到完整的笔记工作区。

QuickNote is a local Markdown scratchpad for macOS. Open a compact note window without switching to a full notebook workspace.

## 下载 · Download

- [下载 QuickNote / Download QuickNote](https://github.com/wangjianghu/QuickNote-Releases/releases/latest)
- 当前安装包适用于 Apple Silicon（arm64），要求 macOS 13 或更新版本。
- The current installer is for Apple Silicon (arm64) and requires macOS 13 or later.
- 解压 ZIP，打开 `QuickNote.app`。也可先将它拖入「应用程序」。应用内可在「设置 → 检查更新」查看新版本，安装由用户手动完成。
- Unzip the download and open `QuickNote.app`, or move it to Applications first. Use **Settings → Check for Updates** to find a newer release and install it manually.

## 核心功能 · Core features

| 中文 | English |
| --- | --- |
| **快速唤起**：通过 Dock、菜单栏或自定义全局快捷键打开笔记。 | **Quick access:** Open a note from the Dock, menu bar, or a configurable global shortcut. |
| **本地 Markdown**：编辑带行号的源文本、查找内容并切换预览；笔记保存在你选定的文件夹。 | **Local Markdown:** Edit with line numbers, search your text, and switch to a rendered preview. Notes live in the folder you choose. |
| **笔记管理**：从文件夹树和笔记列表切换笔记，或打开上次编辑的笔记。 | **Note navigation:** Browse notes and folders, or reopen the last note you worked on. |
| **小窗与悬浮 Logo**：可置顶笔记；点击工具栏 Logo 收起，点击屏幕边缘的 Logo 恢复原窗口。悬浮图标可拖动和调节不透明度。 | **Compact and floating modes:** Pin a note, or click the toolbar logo to reduce the window to a draggable edge badge. Click the badge to restore the editor; its opacity is adjustable. |
| **桌面设置**：可选择是否让笔记窗口跟随 macOS 桌面。 | **Desktop preference:** Choose whether the note window follows your macOS desktop. |

收起窗口不等同于保存。要写入本地文件，请正常保存或关闭笔记。

Collapsing the window does not save the note. Save or close the note normally to write it to disk.
